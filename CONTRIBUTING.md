# Help make homework feel smaller

Ideas, accessibility improvements, setup simplification, tests, and documentation are welcome. Especially useful: helping a parent get a private copy running without needing a developer beside them.

Use synthetic exercises and fake identities in examples, screenshots, fixtures, and tests. Never include real children's work or family configuration. Preserve parent/student access boundaries, private answer guides, saved revisions, and the distinction between teacher assignments and extra practice.

Run the Python and JavaScript checks in README.md. For authentication changes, add meaningful authorization tests. For changes to saved data, document migration and rollback behavior. Keep local use possible, and keep provider usage billed to the installation owner's own API key.
